# MyBike

MyBike is a modern, fully responsive landing page designed for an innovative city bike brand. The purpose of the project is to build a clean, production-ready product presentation page. It showcases an innovative lineup of urban electric bicycles, highlights their premium tech specs, and provides an intuitive layout optimized for high conversion and seamless user experience.

## Technologies Used

### Core
* **HTML5** — Semantic and accessible structure
* **SASS / SCSS (v6.4.1)** — Advanced styling, modular nested architecture, and design-system variables

### UI/UX
* **BEM Methodology** — Component naming convention for clean and scalable CSS
* **CSS Grid & Flexbox** — Responsive layout orchestration and fluid component alignment
* **Pure CSS State Management** — Advanced navigation, interactive mobile menu dropdowns, and form behaviors.

### Development & Deployment
* **Parcel (v2.12.0)** — Web application bundler and compilation tool
* **Stylelint (v16.7.0)** — SCSS code quality and style linting
* **GitHub Pages** — Project hosting and continuous deployment

## Getting Started
Follow these instructions to set up and run the project locally on your machine:

1. Clone the repository:
```bash
git clone https://github.com/kkruslan/MyBike.git
cd MyBike
```
2. Install the necessary dependencies:
```bash
npm install
```
3. Run the project locally in development mode:
```bash
npm start
```

This will start a local development server, and you can view the website in your browser.
